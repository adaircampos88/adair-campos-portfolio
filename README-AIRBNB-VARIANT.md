# Airbnb-inspired portfolio navigation variant

This experimental version keeps the existing portfolio content, project assets, CV, light/dark themes and accessibility controls while changing the responsive shell.

## Responsive navigation

- **Wide desktop:** name/mark on the left, centred pill navigation, utilities on the right.
- **Tablet:** the centre navigation compresses to icon-only controls while contact and theme remain visible.
- **Mobile:** a minimal top bar is paired with a persistent five-item bottom navigation for Home, Work, About, CV and Contact.
- **Case studies:** a compact horizontal section navigator appears below the main header.

## Homepage layout

- The hero sits in a large rounded content canvas.
- The three selected projects use a consistent image-first card system.
- On mobile, project cards become a swipeable, scroll-snapping carousel.

This is an Airbnb-inspired interaction model, not a visual or branded copy of Airbnb.
